写在前面
--------
这是星露谷物语（Stardew Valley）的 MOD 整合包，包含大型剧情拓展
（SVE / 里奇赛德村 / 东斯卡普村）、大量功能与美化模组，以及
X过、山谷女孩 等额外内容扩展。

本包不含游戏本体，需要 Steam 正版星露谷才能使用。


一、从零安装（六步）
--------------------

第 1 步 · 准备游戏本体
  在 Steam 购买并安装《星露谷物语》（Stardew Valley）。
  本包只提供模组，不提供游戏本体。

第 2 步 · 解压本压缩包
  把 【星露谷整合包】v1.0.zip 解压到任意位置，例如：
      D:\星露谷整合包\
  解压后你会看到：
      【星露谷整合包】v1.0\
      ├── MODS\                      ← 152 个模组文件夹
      ├── SMAPI 4.5.2 installer\     ← 模组加载器安装包
      ├── 使用说明书.txt             ← 本文件
      ├── MOD数量及汉化说明.txt
      ├── 一定要看！！启动注意！！.txt
      └── 致谢.txt

第 3 步 · 安装 SMAPI（模组加载器）
  进入 SMAPI 4.5.2 installer\ 文件夹，双击
      install on Windows.bat
  按提示安装（一路确认即可）。
  装完后游戏目录里会多出一个 StardewModdingAPI.exe，以后都用它启动。

  游戏目录在哪？
  Steam 库 → 右键《星露谷物语》→ 管理 → 浏览本地文件。
  默认路径类似：
      C:\Program Files (x86)\Steam\steamapps\common\Stardew Valley

第 4 步 · 安装模组
  打开解压出来的 MODS\ 文件夹，全选里面的所有文件夹（Ctrl+A），
  复制（Ctrl+C），粘贴（Ctrl+V）到游戏目录的 Mods\ 文件夹内。
  - 游戏目录里没有 Mods\ 文件夹就自己新建一个
  - 复制进去的是文件夹本身，不要再点进去只复制里面的东西
  - 提示覆盖时选「是」（代表你之前装过旧版，覆盖即可）

第 5 步 · 启动游戏
  双击游戏目录里的 StardewModdingAPI.exe 启动。
  ★ 不要用 Steam 的「开始游戏」按钮启动——那样不加载任何模组！

第 6 步 · 首次启动
  第一次加载需要 1~3 分钟，黑窗口会滚动很多行文字，属正常现象。
  ★ 加载期间不要乱点鼠标，耐心等窗口跑完、游戏画面出现。
  ★ 黑窗口启动后会自动最小化，不用管它，游戏关了它会自动关。


二、开新档 / 老档须知
---------------------

★ 本包强烈建议开新档游玩。

为什么：
  SVE / 里奇赛德村 / 东斯卡普村 会从游戏初期就改动剧情、地图和事件，
  用老存档会跳过这些内容，体验残缺。

老档硬要进怎么办：
  1. 先备份存档（见下方「七、备份须知」）
  2. 删除文件夹：
     Mods\【大型拓展】爷爷的农场-SVE农场拓展
     （它会改写农场布局，老档不删它可能出问题）
  3. 其余模组可以保留，但剧情缺失请勿见怪

关于存档重名：
  如果你的电脑上还装着 Steam 原版并开了云同步，两个环境的存档
  放在同一个目录，重名角色会互相覆盖——建档时用不同的角色名。


三、启动与配置菜单
-------------------

启动方式（再强调一遍）：
  双击游戏目录 StardewModdingAPI.exe
  不是 Steam 的「开始游戏」

每个模组怎么设置：
  游戏内按 ESC → 菜单里选择「配置菜单」（Generic Mod Config Menu）。
  所有带设置项的模组都在这里调：键位、开关、显示选项、难度等。
  遇到不熟悉的模组，先来这里看看有什么可调的。


四、常用按键速查
----------------
（以下为默认键位，个别可在「配置菜单」内修改；带 ? 的以游戏内为准）

  P            打开 CJB 作弊菜单（传送、无敌、刷物品等巨量功能）
  F1           对着任何东西按一下，查看它的全部信息
  N            查看今天可触发的事件列表（事件查找）
  M            打开地图（装有「NPC显示在地图上」，可看 NPC 位置）
  K            方便的库存：一键把物品堆叠进附近的箱子
               （按住 左Alt 可锁定物品，不被自动堆叠）
  End          手机开关（PageDown 旋转手机）
  SHIFT+1      随时随地自定义角色（改外貌/性别）
  U            自动化：显示机器-箱子的逻辑连接层
  地图传送      打开地图，左键点有名字的地点即可传送
  钓鱼助手      自动钓鱼/自动开宝箱（默认键在配置菜单查看）
  拖拉机        在罗宾处购买拖拉机棚；绑定激活键后召唤
               （强烈建议先去配置菜单绑定键位）
  化妆镜        皮埃尔商店购买；装备后左键进入衣柜界面

常用功能模组一览（都不用按键，装了就生效）：
  好感度不会下降 / 可购买的更大背包 / 可以佩戴更多戒指 /
  礼物助手（社交页显示喜好）/ 镰刀可收获任何作物 /
  马匹可通过一格宽 / 任何东西可以卖掉 / 沙漠矿洞电梯 /
  作物可穿过 / 自动开启栅栏门 / 箱子可拿起（空手右键）/
  可切换宝箱 / 池中鱼（池子显示可钓鱼种）/ UI2（范围与信息显示）/
  甜蜜多角恋 / 邮件服务（邮箱远程升级工具、交付、找回物品）


五、可选内容：删除与替换
------------------------

本包的模组都按中文文件夹名分类，介意或不喜欢的内容直接删除
对应文件夹即可，不会影响其他模组运行：

  · 介意 X过、山谷女孩 等额外扩展：
      删除 Mods\ 下对应名字的文件夹（中文名一看便知）

  · 想换立绘：
      删除 Mods\ 下所有【立绘】开头的文件夹，换上你喜欢的立绘模组
      （直接粘贴进去，旧的删掉）

  · 想换地图美化风格：
      删掉旧的【地图美化】开头的文件夹，再放入新的美化模组
      （旧的不删直接放新的会冲突）

  · 不想要某个功能：
      功能类模组绝大多数可以单独删除对应文件夹，删了就没这个功能

删除后下次启动即生效，无需其他操作。


六、常见问题（FAQ）
-------------------

Q1 启动窗口有一行红字？
   红色 = 某个模组没能正常加载。本包发布时不含红字；
   如果你删改文件夹后出现红字，多半是删漏了依赖——
   优先怀疑你刚删/刚加的那个文件夹。

Q2 启动窗口有紫字？
   紫色 = 有模组可以更新。不影响游玩，可以无视。
   ★ 不会折腾 MOD 的话请勿手动单独更新某个模组，
     更新顺序和依赖最容易把包搞坏。

Q3 某个 MOD 不起作用？
   先重启游戏；还不行就重装一遍 SMAPI（第 3 步）。

Q4 游戏界面某处显示不正常（比如信息栏没了）？
   退回主菜单，重新进游戏，一般就好了。

Q5 能加别的 MOD 吗？
   可以，但不建议乱加。加之前想清楚：
   本包已做兼容调优，外来模组可能与包内模组冲突，
   出问题请自行承担（或先来反馈，确认后再加）。

Q6 请勿擅自修改模组文件夹名、文件夹层级或往里塞东西！
   这会破坏配置菜单和读取顺序，出问题很难查。

Q7 怎么反馈问题？
   带上这个文件：
   %APPDATA%\StardewValley\ErrorLogs\SMAPI-latest.txt
   （直接把路径粘贴到资源管理器地址栏就能打开）


七、备份须知
------------

MOD 玩法推荐新档；用老档前一定要先备份存档：

  存档位置：把下面路径粘贴到资源管理器地址栏打开
      %APPDATA%\StardewValley\Saves
  把里面对应你角色名的文件夹整个复制一份即可。

游戏本体也建议在 Steam 里做一次「验证游戏文件完整性」的准备：
万一模组把本体文件搞乱，验证一次就能还原本体
（模组文件在 Mods\ 文件夹里，不会被验证清掉）。
