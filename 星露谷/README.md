## 三、快速上手

### 我要改 Steam 环境的 MOD
1. 读 `技术笔记-汉化与DLL修改.md`（**必读**，含所有坑）
2. 查 `Steam环境-MOD记录.md` 里这个 MOD 是否已处理过
3. 改前**备份**到 `汉化备份\<日期>-<用途>\`
4. 改后验证（方法见技术笔记）

### 我要玩整合包环境
1. 读 `整合包环境-使用记录.md`
2. 注意：**作者强烈建议开新档**（SVE/RSV/ES 会改初期剧情）
3. 若必须用老档：删 `Mods\【大型拓展】爷爷的农场-SVE农场拓展`

### 我遇到游戏问题
1. 看 SMAPI 日志：`%APPDATA%\StardewValley\ErrorLogs\SMAPI-latest.txt`
2. 查 `Steam环境-MOD记录.md` 的「已知问题」和「假问题」章节（**很多警告是正常的**）

### 我要打发布包（对外分享）
1. 试算：`python -X utf8 发布\build-release.py --dry-run`
2. 出包：`python -X utf8 发布\build-release.py`（默认 v1.0，约 1 分钟）
3. 产物：`MOD上传\【星露谷整合包】v<版本>.zip`（师爷式结构 = MODS + SMAPI + 4 个说明文本，单 ZIP）
4. 更新模组清单：`python -X utf8 发布\build-release.py --manifest` → `发布\mod-manifest.csv`
5. ZIP 传网盘后，把链接记进 `MOD上传\分发链接.md`（同步入库）

### 我要更新线上仓库（game-mods）
1. 改完 `文档\` `工具\` `发布\` 后跑：`powershell -ExecutionPolicy Bypass -File 工具\sync-repo.ps1`（**单向**镜像到 `D:\game-mods\星露谷`）
2. `git -C D:\game-mods add -A` → `commit` → `push`
3. 压缩包、stage、游戏本体永不入库（仓库 `.gitignore` 兜底）；**同步前不要在 game-mods 里手改文件**（镜像会覆盖）
